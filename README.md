# Aplicatie Motivare Angajati / Employee Motivation Web Application

## 🇷🇴 Română

### 1. Descrierea proiectului

#### 1.1 Obiectivul proiectului

Scopul acestui proiect este dezvoltarea unei aplicații web care să faciliteze încurajarea și motivarea personalului unei companii prin administrarea eficientă a bonusurilor, comisioanelor și organizarea de evenimente. 

De asemenea, aplicația va furniza statistici relevante pentru evaluarea performanțelor și a impactului inițiativelor de încurajare.

#### 1.2 Scopul documentului

Scopul acestui document este să descrie pe scurt proiectul și să ofere informațiile necesare pentru înțelegerea și utilizarea aplicației web de încurajare a personalului.

Aplicația va gestiona eficient bonusurile, comisioanele, organizarea evenimentelor și furnizarea de statistici pentru evaluarea performanțelor angajaților.

#### 1.3 Contextul proiectului

Aplicația are ca scop îmbunătățirea gestionării și monitorizării beneficiilor oferite angajaților, facilitând comunicarea și motivarea în cadrul companiei.

### 2. Funcționalități

- gestionarea bonusurilor angajaților;
- gestionarea comisioanelor;
- organizarea și administrarea evenimentelor;
- monitorizarea beneficiilor oferite angajaților;
- furnizarea de statistici privind performanțele;
- sprijinirea procesului de motivare și încurajare a personalului.

### 3. Tehnologii

- Java
- Java Web
- Apache Tomcat
- HTML
- Eclipse / IDE Java

### 4. Structura proiectului

```text
aplicatie-motivare-angajati/
├── src/
│   └── main/
│       ├── java/
│       │   └── Angajati.java
│       └── webapp/
│           ├── index.html
│           ├── META-INF/
│           │   └── MANIFEST.MF
│           └── WEB-INF/
│               └── web.xml
├── Documentation/
│   ├── documentatie.docx
│   └── documentatie.pdf
└── README.md
```

### 5. Rulare

1. Importați proiectul într-un IDE Java, de exemplu Eclipse.
2. Configurați Apache Tomcat.
3. Adăugați proiectul pe server.
4. Porniți serverul Tomcat.
5. Accesați aplicația din browser.

## 🇬🇧 English

### 1. Project description

#### 1.1 Project objective

The objective of this project is to develop a web application designed to encourage and motivate company employees through efficient management of bonuses, commissions, and events. 

The application will also provide relevant statistics for evaluating employee performance and the impact of motivation initiatives.

#### 1.2 Document purpose

The purpose of this document is to briefly describe the project and provide the information necessary to understand and use the employee motivation web application.

The application will efficiently manage bonuses, commissions, events, and statistics used to evaluate employee performance.

#### 1.3 Project context

The application aims to improve the management and monitoring of benefits offered to employees while facilitating communication and motivation within the company.

### 2. Features

- employee bonus management;
- commission management;
- event organization and management;
- monitoring of employee benefits;
- performance-related statistics;
- support for employee motivation and engagement.
